# Smart Event Management System

## Features
- Participant Login and Signup
- Organizer Login and Signup
- Organizer Dashboard
- Participant Dashboard
- Add Events
- View Events
- Event Registration
- My Registrations Page
- Event-only AI Chatbot
- SQLite Local Database
- Docker, Kubernetes and Jenkins files

## Run Backend

```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

## Run Frontend

Open:

```text
frontend/index.html
```

Right click and select:

```text
Open with Live Server
```
